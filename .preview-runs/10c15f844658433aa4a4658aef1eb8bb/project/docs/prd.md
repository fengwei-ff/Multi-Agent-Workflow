# 待办事项网页应用 PRD

## 背景
用户需要一个简单的待办事项管理工具，用于记录和跟踪日常任务，核心诉求是能够方便地新增、查看、编辑和删除待办事项。

## 目标
构建一个运行在浏览器中的网页应用，用户无需安装即可使用，支持对待办事项进行增、删、改、查操作，并在刷新页面后数据不丢失。

## 范围
- 纯前端网页应用，数据保存在浏览器本地存储（localStorage）。
- 支持单用户操作，不涉及账号体系。
- 支持以下核心操作：新增待办、查看列表、编辑内容、删除待办、切换完成状态。

## 非目标
- 不包含用户注册、登录、多用户协作。
- 不包含后端服务或云同步。
- 不包含任务优先级、分类、标签、截止日期、提醒等高级功能。
- 不包含子任务或任务拆分。

## 功能点
1. **新增待办**：输入框填写内容，点击“添加”按钮或回车键，将待办事项加入列表。
2. **查看列表**：以列表形式展示所有待办事项，每条显示内容、完成状态和创建时间。
3. **编辑待办**：点击每条待办的“编辑”按钮，将内容变为可编辑状态；修改后点击“保存”更新内容，点击“取消”放弃修改。
4. **删除待办**：点击每条待办的“删除”按钮，弹出确认提示；确认后删除该条，取消则保留。
5. **完成状态切换**：每条待办有复选框，勾选后标记为“已完成”，文字显示删除线；取消勾选恢复为“未完成”。
6. **数据持久化**：所有待办数据存入 localStorage，刷新或重新打开页面后数据仍然存在。
7. **空内容校验**：输入内容为空或仅包含空白字符时，不允许新增，并给出提示文案。

## 验收标准
- AC1: 打开应用后，页面包含待办输入框和“添加”按钮。
- AC2: 在输入框中输入“买菜”，点击“添加”按钮，列表中出现一条内容为“买菜”的待办记录，状态为“未完成”，并显示创建时间。
- AC3: 在输入框中输入“买菜”后按回车键，与点击“添加”效果相同，列表新增该记录。
- AC4: 输入框为空或仅含空格时，点击“添加”或按回车，列表不新增记录，且页面出现“待办内容不能为空”的提示。
- AC5: 每条待办记录右侧有“编辑”按钮，点击后该条内容变成可编辑输入框，同时出现“保存”和“取消”按钮。
- AC6: 在编辑状态修改内容为“买水果”，点击“保存”，列表更新为“买水果”，且“买水果”之外的其他待办内容不变。
- AC7: 在编辑状态点击“取消”，修改内容不生效，列表恢复为原内容。
- AC8: 每条待办记录右侧有“删除”按钮，点击后弹出确认对话框（内容如“确定删除该待办？”）。
- AC9: 在确认对话框中点击“确定”，该条待办从列表中消失；点击“取消”，该条待办仍保留。
- AC10: 每条待办记录有复选框，初始未勾选；勾选后该条文字出现删除线，状态变为“已完成”；再次取消勾选，删除线消失，状态恢复为“未完成”。
- AC11: 新增若干待办并勾选部分为完成后，刷新页面，所有记录（包括完成状态）仍然存在且与刷新前一致。
- AC12: 删除某条待办并刷新页面后，该记录不再出现，其余记录不受影响。
- AC13: 连续新增 10 条待办，列表能完整展示全部记录，无内容丢失或渲染错误。

## 业务规则
- 每条待办必填内容，且内容在去除首尾空格后不能为空。
- 待办列表默认按创建时间从旧到新排序。
- 编辑时，若将内容改为空或仅空格，点击“保存”无效，并提示“待办内容不能为空”。
- 已完成的待办仍可编辑、删除。
